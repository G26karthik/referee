# Reviewer feedback closure

Every comment received on the first manuscript, with a status and the evidence behind it.

- **RESOLVED** means the requested correction is implemented and there is a current
  artifact, test or manuscript section demonstrating it.
- **PARTIAL** means a mechanism or protocol exists but the requested empirical
  demonstration does not, or the closure rests on a judgement a machine cannot make.
- **OPEN** means the run and the manuscript do not answer it.

A protocol, a test fixture or a planned route is not counted as an executed scientific
result. Two items below were downgraded from RESOLVED after this phase audited the code
rather than the previous closure document; both downgrades are marked.
